## 실습 프롬프트

모두 `C:\UnityProjects\MyFirstGame`에서 연 Claude Code 세션(권한 모드 manual)에 순서대로 입력합니다.

### 03-1. Git 초기화와 첫 커밋

```text
이 Unity 프로젝트를 Git 저장소로 초기화해 주세요.
Unity 프로젝트에 맞는 .gitignore를 추가하고(Library, Temp, Logs, UserSettings 등 제외),
현재 상태를 "프로젝트 생성 직후" 메시지로 첫 커밋해 주세요. 원격 저장소는 만들지 마세요.
```

### 03-2. 게임 기획서

```text
2D 서바이벌 액션 게임을 만들려고 합니다. 아직 코드나 씬은 만들지 말고,
먼저 한 페이지 분량의 게임 기획서를 docs/GameDesign.md 로 작성해 주세요.

- 장르: 위에서 내려다보는 2D 서바이벌. 플레이어는 화면 중앙에서 시작해 방향키 또는 WASD로 움직이고,
  사방에서 몰려오는 적을 자동 공격으로 물리치며 최대한 오래 버팁니다.
- 그래픽: 처음에는 이미지 에셋 없이 단색 도형만 씁니다. 플레이어는 흰색 사각형, 적은 빨간색 사각형입니다.
  UI·연출 단계에서 라이선스가 명확한 무료 스프라이트와 효과음으로 바꿉니다.
- 기획서에 넣을 것: 핵심 규칙, 조작, 승패 조건, 화면 구성, 그리고 아래 순서 그대로의 단계별 구현 계획
  1) 첫 화면: 배경과 플레이어만 있는 게임 씬
  2) 이동과 적: 플레이어 이동, 적 생성과 추적
  3) 게임 규칙: 충돌·피해, 자동 공격, 체력·점수·생존 시간, 난이도, 게임오버·재시작
  4) UI와 연출: 시작 화면·일시정지, 체력 바·점수판, 스프라이트·애니메이션, 효과음·배경음악, 파티클
  5) 자동 테스트: EditMode·PlayMode 테스트
  6) 빌드: Windows 실행 파일과 WebGL 웹 게임
```

Claude가 커밋할지 물으면:

```text
네, "게임 기획서 추가" 메시지로 커밋해 주세요.
```

### 03-3. 프로젝트 상태 조사

```text
이 Unity 프로젝트의 현재 상태를 파악해서 요약해 주세요. 파일은 수정하지 마세요.
- Unity 버전, 렌더 파이프라인, 주요 패키지(입력 방식 포함)
- 현재 열려 있는 씬과 그 안의 오브젝트
실행 중인 Unity Editor가 있으면 Unity CLI로 직접 확인하세요.
```

### 03-4. 첫 게임 씬

```text
기획서의 첫 단계로, 게임 씬의 기본 화면만 만들어 주세요.

- Assets/Scenes/Game.unity 씬을 새로 만들어 열고, 빌드 설정의 씬 목록에서 SampleScene을 빼고 Game을 첫 번째로 두세요.
- 카메라는 2D 정사영(Orthographic), 배경은 어두운 단색으로 합니다.
- 화면 중앙에 "Player"라는 이름의 흰색 사각형 하나만 둡니다. 이동 같은 스크립트는 아직 만들지 마세요.
- 실행 중인 Unity Editor를 Unity CLI로 조작하고, .unity 씬 파일을 직접 편집하지 마세요.

작업이 끝나면 씬을 저장하고, 게임 화면을 캡처해 결과를 확인한 뒤
콘솔에 오류나 경고가 있는지 보고해 주세요. 확인용 캡처 파일은 프로젝트에서 지워 주세요.
마지막으로 "첫 게임 씬" 메시지로 커밋해 주세요.
```

### 03-5. CLAUDE.md 개발 규칙

```text
앞으로 이 프로젝트에서 지킬 개발 규칙을 프로젝트 루트의 CLAUDE.md 로 정리해 주세요.

- 실행 중인 Unity Editor가 있으면 Unity CLI(unity command)로 조작하고, .unity·.prefab 파일을 직접 편집하지 않는다.
- 스크립트는 Assets/Scripts, 씬은 Assets/Scenes 에 둔다.
- 입력은 Input System 패키지를 사용한다.
- 한 번에 한 기능만 구현하고, 요청 범위 밖의 파일은 수정하지 않는다.
- 기능을 구현하면 컴파일 오류와 콘솔 오류를 확인하고, 결과를 캡처해 확인한 뒤 보고한다.
- unity command eval 은 상태 확인과 간단한 조작에만 쓰고, 큰 변경 전에는 Git 커밋으로 복구 지점을 만든다.
- 게임 기획은 docs/GameDesign.md 를 따른다.

작성 후 "개발 규칙 추가" 메시지로 커밋해 주세요.
```
