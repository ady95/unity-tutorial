# MyFirstGame 게임 기획서

> 위에서 내려다보는 2D 서바이벌 액션 게임 · Unity 6000.3 (URP 2D, Input System)
> 아래 수치는 모두 첫 버전의 초깃값이며, 플레이해 보면서 조정합니다.

## 1. 게임 개요

플레이어는 화면 중앙에서 시작합니다. 사방에서 몰려오는 적을 자동 공격으로 물리치며 최대한 오래 버팁니다.
조작은 이동뿐이고, 공격은 자동입니다. 그래서 적을 피하면서 공격하기 좋은 자리를 잡는 것이 핵심입니다.

## 2. 핵심 규칙

| 항목 | 규칙 (초깃값) |
|---|---|
| 플레이어 | 체력 100, 이동 속도 5 유닛/초, 화면(아레나) 밖으로 나갈 수 없음 |
| 적 생성 | 화면 바로 바깥 네 방향의 무작위 위치에서 1.5초마다 1마리 |
| 적 행동 | 플레이어를 향해 직선으로 추적 (속도 2 유닛/초), 체력 1 |
| 피해 | 적과 닿으면 플레이어 체력 −10, 이후 0.5초 동안 무적 |
| 자동 공격 | 0.5초마다 사거리(6 유닛) 안의 가장 가까운 적에게 탄환 발사, 탄환 1발 = 피해 1 |
| 점수 | 적 처치 1마리당 +10점, 생존 1초당 +1점 |
| 난이도 | 30초마다 적 생성 간격 −10%(최소 0.3초), 적 속도 +5%(최대 4 유닛/초) |

## 3. 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 8방향 이동 (대각선 이동도 같은 속도가 되도록 정규화) |
| Esc / P | 일시정지 · 재개 |
| Enter / Space | 시작 화면에서 시작, 게임오버 화면에서 재시작 |

입력은 프로젝트에 있는 `Assets/Settings/InputSystem_Actions.inputactions`의 `Move` 액션을 씁니다.

## 4. 승패 조건

- **패배:** 플레이어 체력이 0이 되면 게임오버. 생존 시간과 최종 점수를 보여 주고 재시작할 수 있습니다.
- **승리:** 따로 없는 무한 생존 방식입니다. 최고 점수를 기록(PlayerPrefs)해 이전 기록에 도전하게 합니다.

## 5. 화면 구성

```
┌──────────────────────────────────────────┐
│ HP ███████░░░  80/100         점수 1,230 │
│                               시간 02:15 │
│        ■                                 │
│                    □ ← 플레이어(흰색)     │
│   ■ ← 적(빨간색)                ■        │
│                                          │
└──────────────────────────────────────────┘
```

- 카메라는 고정된 직교 투영(Orthographic)이고, 화면 전체가 아레나입니다. 배경은 어두운 단색입니다.
- 1~3단계에서는 이미지 에셋 없이 단색 사각형만 씁니다. 플레이어는 흰색, 적은 빨간색, 탄환은 노란색입니다.
- 4단계에서 라이선스가 명확한 무료 스프라이트와 효과음(예: CC0)으로 바꾸고, 출처와 라이선스를 `docs/CREDITS.md`에 적습니다.

## 6. 단계별 구현 계획

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1. 첫 화면 | 게임 씬 생성, 카메라·배경색 설정, 화면 중앙에 플레이어(흰색 사각형) 배치 | Play를 누르면 어두운 배경 가운데에 흰 사각형이 보임 |
| 2. 이동과 적 | 플레이어 이동(WASD·방향키, 화면 경계 제한), 적 생성기, 플레이어 추적 | 플레이어가 움직이고, 화면 밖에서 나타난 빨간 사각형이 플레이어를 따라옴 |
| 3. 게임 규칙 | 충돌·피해와 무적 시간, 자동 공격(탄환), 체력·점수·생존 시간, 시간에 따른 난이도 상승, 게임오버·재시작 | 적을 처치하면 점수가 오르고, 체력이 0이 되면 게임이 멈춘 뒤 재시작할 수 있음 |
| 4. UI와 연출 | 시작 화면·일시정지, 체력 바·점수판, 스프라이트·애니메이션, 효과음·배경음악, 파티클(피격·처치) | 시작부터 게임오버까지 화면 안내와 소리가 갖춰지고, 에셋 출처가 기록됨 |
| 5. 자동 테스트 | EditMode: 체력·점수·난이도 계산 같은 순수 로직 / PlayMode: 이동, 적 추적, 충돌 피해, 게임오버 흐름 | Test Runner에서 모든 테스트 통과 |
| 6. 빌드 | Windows 실행 파일(.exe), WebGL 웹 게임 | 두 빌드 모두 실행해 처음부터 게임오버·재시작까지 플레이 가능 |

### 구현 메모

- **테스트를 고려한 구조:** 체력·점수·난이도 같은 규칙은 MonoBehaviour와 분리된 일반 C# 클래스로 만들어, 5단계에서 EditMode로 바로 검증할 수 있게 합니다.
- **물리:** 충돌은 Rigidbody2D(Kinematic)와 트리거 Collider2D로 처리하고, 레이어를 Player · Enemy · Projectile로 나눕니다.
- **WebGL:** 브라우저는 사용자 입력 전에 소리를 막으므로, 배경음악은 시작 화면에서 첫 입력을 받은 뒤 재생합니다.
- 각 단계를 마칠 때마다 Git에 커밋합니다.
