# 6장 실습 자료 — AI로 게임 규칙과 전투 시스템 완성하기

책: [6장](https://wikidocs.net/book/21663)

[Scripts](Scripts) 폴더에는 6장을 마친 시점의 게임 스크립트 12개가 모두 들어 있습니다(5장 스크립트 중 6장에서 수정된 EnemySpawner·EnemyChaser 포함). Health·Score·Difficulty는 Unity와 분리된 일반 C# 클래스로, 8장 자동 테스트에서 씁니다.

스크립트만으로는 동작하지 않습니다. 충돌 영역, 레이어, 프리팹·씬 연결은 Claude Code가 Editor에서 한 작업입니다. AI의 결과는 실행할 때마다 다르므로 내 결과와 비교하는 용도로 쓰세요.

## 실습 프롬프트

새 Claude Code 세션에서 순서대로 입력합니다. 저자는 auto 모드로 측정했습니다.

### 06-1 시작 전. 보고 언어 규칙

```text
지난 세션에서 보고가 영어로 바뀐 적이 있습니다. 앞으로 모든 보고와 설명을 한국어로 하도록 CLAUDE.md에 규칙을 한 줄 추가하고 "보고 언어 규칙 추가" 메시지로 커밋해 주세요.
```

### 06-1. 충돌과 피해

```text
기획서 3단계 중 충돌과 피해를 구현해 주세요.

- 플레이어와 적에 2D 충돌 영역을 붙여, 적이 플레이어에 닿으면 플레이어 체력이 기획서의 접촉 피해만큼 줄어듭니다.
- 피해를 받은 뒤에는 기획서의 무적 시간 동안 다시 피해를 받지 않습니다.
- 플레이어 체력과 피해 계산은 기획서 구현 메모대로 Unity와 분리된 일반 C# 클래스로 만들어, 8장에서 EditMode 테스트로 확인할 수 있게 합니다.
- 플레이어가 적보다 항상 앞에 그려지게 합니다.
- 체력이 0이 되었을 때의 처리(게임오버)는 아직 만들지 마세요.

Play 모드에서 적이 플레이어에 닿게 한 뒤, 체력 값이 피해만큼 줄고 무적 시간 동안은 더 줄지 않는지 값으로 확인해 주세요.
확인이 끝나면 Play 모드를 끄고 바꾼 설정을 원래대로 되돌린 뒤 "충돌과 피해" 메시지로 커밋해 주세요.
```

### 06-2. 자동 공격

```text
기획서 3단계 중 자동 공격을 구현해 주세요.

- 기획서의 간격마다 사거리 안의 가장 가까운 적에게 노란색 작은 사각형 탄환을 발사합니다. 탄환 속도와 피해는 기획서 값을 씁니다(기획서에 없으면 알맞게 정하고 보고해 주세요).
- 탄환이 적에게 맞으면 적 체력이 줄고, 0이 되면 적이 사라집니다. 화면 밖으로 나간 탄환도 사라집니다.
- 점수와 화면 표시는 아직 만들지 마세요.

Play 모드에서 몇 초 진행한 뒤 일시정지해, 탄환이 가장 가까운 적을 향해 나가는지와 맞은 적이 사라졌는지 값과 캡처로 확인해 주세요.
확인이 끝나면 Play 모드를 끄고 바꾼 설정을 원래대로 되돌린 뒤 "자동 공격" 메시지로 커밋해 주세요.
```

### 06-3. 점수와 생존 시간

```text
기획서 3단계 중 점수와 생존 시간을 구현해 주세요.

- 생존 시간을 초 단위로 셉니다.
- 점수는 기획서대로 적 처치와 생존 시간으로 계산합니다. 점수 계산도 일반 C# 클래스로 분리합니다.
- 화면에 표시하는 UI는 7장에서 만듭니다. 지금은 값만 관리하고, 콘솔에 5초마다 체력·점수·생존 시간을 한 줄로 출력합니다.

Play 모드에서 약 10초 진행한 뒤 일시정지해, 콘솔 출력과 실제 처치 수·시간으로 점수가 기획서 계산과 같은지 확인해 주세요.
확인이 끝나면 Play 모드를 끄고 바꾼 설정을 원래대로 되돌린 뒤 "점수와 생존 시간" 메시지로 커밋해 주세요.
```

### 06-4. 난이도 상승

```text
기획서 3단계 중 시간에 따른 난이도 상승을 구현해 주세요.

- 기획서의 주기마다 적 생성 간격과 적 속도를 기획서의 비율과 한계값대로 바꿉니다.
- 난이도 계산(몇 초에 생성 간격·속도가 얼마인지)도 일반 C# 클래스로 분리합니다.

Play 모드에서 첫 난이도 상승 시점을 지나 일시정지해, 생성 간격과 적 속도가 기획서 계산값으로 바뀌었는지 값으로 확인해 주세요.
확인이 끝나면 Play 모드를 끄고 바꾼 설정을 원래대로 되돌린 뒤 "난이도 상승" 메시지로 커밋해 주세요.
```

### 06-5. 게임오버와 재시작

```text
기획서 3단계의 마지막으로 게임오버와 재시작을 구현해 주세요.

- 플레이어 체력이 0이 되면 게임이 멈추고(적과 플레이어, 생성, 공격이 모두 멈춤) 게임오버 상태가 됩니다.
- 게임오버 상태에서 Enter 또는 Space를 누르면 게임이 처음부터 다시 시작됩니다.
- 게임오버 화면 UI와 최고 점수 저장은 7장에서 만듭니다. 지금은 게임오버와 재시작 때 콘솔에 한 줄씩 출력합니다.

Play 모드에서 체력이 0이 될 때까지 진행해 게임이 멈추는지, simulate_key로 Enter를 눌러 체력·점수·시간이 처음 값으로 돌아가는지 값으로 확인해 주세요.
확인이 끝나면 Play 모드를 끄고 바꾼 설정을 원래대로 되돌린 뒤 "게임오버와 재시작" 메시지로 커밋해 주세요.
```
